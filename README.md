Programa feito em C que faz cálculos de probabilidade. Ele calcula permutações simples e com repetição, combinações simples e com repetição
e arranjos simples e com repetição. Não sei por que eu criei uma função separada para ler um número, isso só me dificultou ao longo
do projeto, se eu fosse melhorar o código começaria tirando aquela função.

Agora se eu fosse querer colocar outras funções, acho que além dos cálculos também faria literalmente as combinações possíveis e mostraria
para o usuário. No caso o usuário insere os valores e o programa mostra combinação por combinação.
